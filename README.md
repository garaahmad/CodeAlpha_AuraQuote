# AuraQuote

A dark-themed Flutter app that blends ancient wisdom with AI-generated insights. Discover curated quotes from Stoics, Sufis, Taoists, Zen masters, and philosophers — or let Google Gemini craft a personalized reflection for you.

## Features

- **Curated Library** — 30+ handpicked quotes from Marcus Aurelius, Seneca, Epictetus, Rumi, Lao Tzu, Alan Watts, Socrates, Aristotle, Buddha, and more
- **AI-Generated Quotes** — Tap "Generate My Aura" to get a unique quote from the Gemini AI model
- **Onboarding Flow** — Three-page introduction (Discover AI Wisdom, Spark Your Muse, Build Your Soul Library)
- **Authentication** — Email/password sign-up and sign-in, plus Google social login (Apple sign-in support included)
- **State Management** — BLoC pattern for auth, quote display, onboarding, and app routing
- **Dark Glassmorphic UI** — Frosted glass panels, radial glow gradients, smooth animations, and a cohesive dark color palette
- **Google Fonts** — Montserrat for UI controls, Playfair Display for quote text
- **Firebase Backend** — Firebase Auth, Cloud Firestore, and platform-specific Firebase configs (Android, iOS, Web)

## Tech Stack

| Layer | Technology |

## Getting Started

### Prerequisites

- Flutter SDK `^3.11.5`
- A Firebase project with Auth (Email/Password, Google, Apple) and Cloud Firestore enabled
- A Google Gemini API key

### Setup

1. Clone the repo and navigate to the project root:

```bash
git clone <repo-url>
cd aura_quote
```

2. Install dependencies:

```bash
flutter pub get
```

3. Create a `.env` file in the project root with your credentials:

```
GEMINI_API_KEY=your_gemini_api_key
FIREBASE_WEB_ID=your_firebase_web_app_id
FIREBASE_ANDROID_ID=your_firebase_android_app_id
FIREBASE_IOS_ID=your_firebase_ios_app_id
```

4. Place your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) in the respective platform directories.

5. Run the app:

```bash
flutter run
```

## Configuration

- **Launcher Icon**: Update `lib/assets/image/image.png` and run `flutter pub run flutter_launcher_icons`
- **Firebase**: Generated options live in `lib/firebase_options.dart` (auto-generated by `flutterfire configure`)
- **Color Scheme**: Customize colors in `lib/constants/constants.dart`
